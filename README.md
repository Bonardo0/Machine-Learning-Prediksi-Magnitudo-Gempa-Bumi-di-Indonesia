# Machine-Learning-Prediksi-Magnitudo-Gempa-Bumi-di-Indonesia
Prediksi Magnitudo Gempa Bumi di Indonesia menggunakan Algoritma Machine Learning XGBoost, dan Random Forest

Indonesia terletak di Cincin Api Pasifik, menjadikannya salah satu negara dengan aktivitas gempa tertinggi di dunia. Estimasi magnitudo gempa yang cepat dan akurat sangat penting untuk respons darurat yang efektif.
Namun, sistem peringatan dini yang ada masih memiliki keterbatasan dalam memprediksi magnitudo secara real-time.
Machine Learning, khususnya algoritma Random Forest dan XGBoost, menawarkan solusi dengan mempelajari pola data gempa secara efisien dan memberikan prediksi yang lebih cepat dan presisi.

Dataset yang digunakan yaitu dataset gempa bumi di indonesia dari BMKG dari tahun 2008 sampai tahun 2025 yang di scraping menggunakan HTML, source dapat dilihat pada link berikut, github.com/kekavigi/repo-gempa.
